⚙️ Configuração Inicial

Para ativar o sistema de login, você precisa conectar ao Supabase.
Crie sua conta gratuita em supabase.com e cole as credenciais do seu projeto abaixo.

✅ Como obter as credenciais:
1. Acesse supabase.com → Crie um projeto
2. Vá em Project Settings → API
3. Copie a Project URL e a anon/public key
⚠️ Execute este SQL no Supabase (SQL Editor):

CREATE TABLE usuarios ( id uuid DEFAULT gen_random_uuid() PRIMARY KEY, nome text NOT NULL, email text UNIQUE NOT NULL, senha_hash text NOT NULL, role text DEFAULT 'user', ativo boolean DEFAULT true, criado_em timestamptz DEFAULT now(), ultimo_acesso timestamptz ); -- Desative RLS para uso com anon key ALTER TABLE usuarios DISABLE ROW LEVEL SECURITY;
